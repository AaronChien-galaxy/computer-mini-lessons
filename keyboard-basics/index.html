先看右下角

打 a b c，會出現什麼？

右下角 中
ㄇㄖㄏ

注音符號，看不懂的字

右下角 A
abc

英文字母，登入就要這個

怎麼換？按一下 Shift，右下角的「中」和「A」會輪流出現。

不能互動時：左邊是中文模式（ㄇㄖㄏ），右邊是英文模式（abc）。

想打大寫字母

怎麼按才對？

1. 打一個大寫 A：按住 Shift 再按 a。

2. 一直打大寫：按 Caps Lock。

3. 回到小寫：再按一次 Caps Lock。

真的鍵盤也可以按

按一個鍵，看它做什麼

點鍵盤上的藍色鍵，或直接按真的鍵。

十根手指各管幾個鍵

手指「回家」的位置

asd fgh jkl;
點上面的按鈕，看每根手指放哪裡。

左手：小指 a、無名指 s、中指 d、食指 f。右手：食指 j、中指 k、無名指 l、小指 ;。F 和 J 有小突起，摸到就知道手指回家了。大拇指放空白鍵。

數字鍵上面藏著符號

按住 Shift，數字變符號

點一個鍵，看它是什麼。真的按住 Shift 也可以。

Shift＋2 是 @（電子郵件用），Shift＋1 是 !，Shift＋3 是 #。

兩個鍵一起按

Ctrl 組合鍵：複製、貼上、復原

① 雙擊文字選起來 ② Ctrl + C 複製 ③ 點一下空白處 ④ Ctrl + V 貼上 ⑤ Ctrl + Z 復原
先雙擊上面的字，把它選起來。

Ctrl＋C 複製，Ctrl＋V 貼上，Ctrl＋Z 復原。先把字選起來才能複製。

登入前的暖身（假帳號）

用鍵盤完成登入

帳號：Amy05@sch　密碼：cat123
點帳號欄開始打。打完用 Tab 跳到密碼，再按 Enter。

帳號 Amy05@sch：A 要大寫（Shift＋a），@ 是 Shift＋2。打完帳號按 Tab 到密碼欄，打完密碼按 Enter 登入。

接下來練習打字

符號小站，四步驟

  1. 1老師機投影，從 Classroom 的連結進入「Shift 符號練習小站」。
  2. 2輸入你的 5 碼號碼：班級 3 碼＋座號 2 碼，再按 Enter。
  3. 3從第一關開始，一關一關往下打，打錯了按倒退。
  4. 4打完一組會得到星星，你的成績會自動送給老師。
